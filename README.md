## Projects

**[SA Data Hub](https://github.com/ubayd-hattas/SA_DataHub)** ([sadatahub.tech](https://sadatahub.tech)). A public platform for South African statistics, built and maintained solo since May 2026. Province and municipality pages from Census 2022, charts of economic, crime and education indicators, CSV downloads, a PostgreSQL schema on Neon, Python data adapters, and a staged-publishing step that stops unapproved data reaching production. Next.js, TypeScript, Tailwind, Recharts, Python, PostgreSQL, Vitest.

**[Evidence Before Erasure](https://github.com/ubayd-hattas/AI_Incident)**. Team project for the Apart x CeSIA AI Incident Response Sprint: how much critical evidence do different collection policies preserve from a live AI incident? The main contrast was a null result, and the report says so.

**[AfriGuard](https://github.com/ubayd-hattas/AfriGuard)**. Team project from the Global South AI Safety Hackathon: a benchmark of 40 seed prompts in seven languages run against four models (1,120 responses). The first-pass scoring used an English-only refusal heuristic, so no attack success rate is claimed here. Validated scoring is the next step.

**[Digital Minds Research](https://github.com/UbaJaz/Digital_Minds_Research)**. Team project from an Apart Research sprint: does an LLM predicting its own output beat a cheap outside observer? Across 9,269 trials, a one-feature "pick the longer reply" rule outperformed Hermes-3's self-prediction.
